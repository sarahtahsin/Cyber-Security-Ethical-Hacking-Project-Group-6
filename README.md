Project Title: Machine Learning Approaches in PDF Malware Detection: An Empirical Study.
Authors: Sarah Tahsin, Novera Ahmed Nirbachita, Nazia Zarin Riti.
Problem Statement: Traditional signature-based PDF malware detection cannot effectively detect new and evasive malware. Existing Machine Learning approaches vary in accuracy, robustness, efficiency, and explainability, creating the need for a comprehensive comparative evaluation.
Research Objective: Compare Machine Learning models for PDF malware detection. Evaluate Machine Learning models against signature-based detection. Assess detection accuracy, computational efficiency, and evasion resistance. Identify important malware features using SHAP and LIME.
Dataset Description: The study utilized the evasive PDF dataset CIC-Evasive-PDFMal2022 from the Canadian Institute for Cybersecurity. The dataset consists of 10,025 records, with the distribution of 5,557 malicious records and 4,468 benign records. There are 31 features in the dataset, including metadata size, document encryption, size of the whole document, and number of pages.
Folder Structure Outline: Inside All_figures, the figures produces by the Google Colab notebook are uploaded. Used_figures folder contains the figures used in the paper. Cyber_codes.ipynb is the main code notebook. PDF_Malware_Detection_Presentation.pptx is the presentation slide of the project. Cyber_Group06_report.pdf is the main report, Cyber_Group06_source.zip is the zipped source code folder.
Installation and Execution Steps: Initially, the dataset was directly downloaded from Kaggle. Then, the codes where implemented on the raw dataset. The code notebook is uploaded in the repository (file name: Cyber_codes.ipynb).
Summary of Results: XGBoost achieved the best performance with 99.50% F1-score and 99.45% accuracy, followed closely by Random Forest (99.20% F1-score). Machine learning models significantly outperformed the signature-based approach, which achieved only 79.74% F1-score. XGBoost and Random Forest maintained over 99% recall on evasive malware samples, demonstrating strong robustness. SHAP and LIME identified JavaScript and metadata size as the most important features for detecting malicious PDFs. Overall, XGBoost provided the best balance of accuracy, speed, robustness, and interpretability, making it the most suitable model for practical PDF malware detection.
